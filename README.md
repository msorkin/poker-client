# Poker Game Client

A multiplayer poker client MVP featuring basic UI and game logic for playing Texas Hold'em poker.

## Features

- Real-time multiplayer gameplay
- Basic poker UI with cards and betting controls  
- Complete Texas Hold'em game flow:
  - Preflop, flop, turn and river betting rounds
  - Showdown logic
  - Pot management
- Player actions (check, bet, fold etc.)
- Amount range validation
- Error handling and game state management

## Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm (v6 or higher)
- Backend server running (see [poker-server](../poker-server))
